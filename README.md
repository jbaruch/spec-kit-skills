# This project has moved

**Spec-Kit Skills has been rebranded to Intent Integrity Kit (IIKit).**

## New Location

**https://github.com/intent-integrity-chain/kit**

## What Changed?

The project is now part of the [Intent Integrity Chain](https://github.com/jbaruch/intent-integrity-chain) methodology - a framework for preserving intent from idea to implementation with cryptographic verification.

**New name**: Intent Integrity Kit
**New tagline**: Closing the intent-to-code chasm
**New commands**: `/iikit-*` (was `/speckit-*`)

## Migration

```bash
# Remove old installation
tessl uninstall tessl-labs/spec-kit

# Install new version
tessl install intent-integrity-chain/kit
```

Then update your skill invocations:
- `/speckit-00-constitution` → `/iikit-00-constitution`
- `/speckit-01-specify` → `/iikit-01-specify`
- ... and so on
